# 课程考核证据清单

课程方案的 40 分功能项和 50 分报告项都需要能在提交材料中被直接核对。下面的顺序适合录制演示视频、截取报告图片和整理 README。

## 功能项（40 分）

| 评分点 | 前端操作 | 后端/文件证据 |
| --- | --- | --- |
| 菜单和页面展示 | 管理员总览、图书、读者、借还、分析、导入导出；读者目录和我的借阅 | `frontend/src/App.tsx`、运行页面截图 |
| 添加 | 总览或图书管理中点击“新增图书”并保存 | `POST /api/v1/books`、保存后的卡片 |
| 删除 | 图书卡片点击“停用”，确认后查看已下架状态 | `DELETE /api/v1/books/{id}`；有借阅时展示业务错误 |
| 修改 | 图书卡片“编辑”，修改价格/库存后保存 | `PATCH /api/v1/books/{id}`、库存前后截图 |
| 查询 | 选择书名、作者、ISBN、分类或编号后检索 | `GET /api/v1/books` 响应和结果页 |
| 文件导入 | 选择课程表头 CSV，预览前几行，确认整批导入 | `POST /api/v1/files/books/import`、成功/失败结果 |
| 文件导出 | 下载图书、读者或借阅 CSV | `GET /api/v1/files/*/export`、下载文件 |
| 功能整合 | 管理员选择读者办理借阅，归还时确认罚款预览，观察库存恢复和总览指标 | `/loans/borrow`、`return-preview`、`return`、`dashboard/stats` |
| 正常启动 | `pnpm dev` 静态演示；`.venv/bin/uvicorn` 本地后端 | `frontend/README.md`、`backend/README.txt` |
| 异常处理 | 错误账号、重复 ISBN、无库存、逾期借阅、非法 CSV 行 | 页面错误提示、稳定错误码、27 项后端测试 |

## 报告项（50 分）

报告建议使用以下 10 个小节，每节保留“操作目标、关键代码、运行结果、截图编号”：

1. 项目背景：图书、读者和借还业务范围，前后端目录结构。
2. “Trea”安装和配置：只放真实安装/配置过程截图，不能用程序生成替代图。
3. 页面展示代码和效果：Google Sans Flex/Noto Sans SC、Material 3 颜色角色、响应式侧栏。
4. 添加图书：表单校验、API 请求、保存后的库存卡片。
5. 删除图书：停用语义、借阅中禁止删除的错误提示。
6. 修改图书：价格、分类和总库存修改，以及借出数量约束。
7. 功能整合：借阅、归还、罚款、库存和首页统计之间的数据流。
8. 生成文件前后：导出 CSV 的表头、文件内容和下载结果。
9. 读取文件效果：CSV 选择、浏览器预览、后端整批校验与导入结果。
10. 个人总结：具体完成内容、测试命令、GitHub Pages 演示方式和局限。

## 推荐录制顺序

使用管理员演示账号完成：登录 → 新增图书 → 编辑图书 → 查询 → 办理借阅 → 归还预览 → 导出 CSV → 数据分析；再使用读者演示账号完成：目录查询 → 图书详情借阅 → 我的借阅 → 打印凭单。每一步停留一秒显示成功提示和页面状态，方便报告截图。

演示模式固定基准日为 `2026-08-31`，刷新会恢复数据。真实后端模式读取本地 SQLite；两种模式使用同一组前端类型和接口路径。
